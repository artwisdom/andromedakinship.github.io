Severity labels & precise filtering

Each alert carries a plain-text severity label — info, notice, or urgent — so enforcement actions and emergency rulemaking stand out from routine commentary. Use /filter to scope the feed by:

  • Jurisdiction — US-CA, EU, or US-multistate.
  • Action type — enforcement, rulemaking, guidance, consultation, legislation, or commentary.
  • Topic — AI, privacy, GDPR, CCPA, or biometric.
  • Minimum severity — so routine commentary never pings the channel if you only want enforcement.

Because the aggregator and the primary sources sometimes cover the same action, RegPing suppresses near-duplicate items so the same development isn't posted twice.
